# Hospital Management System - DBMS

## Project Description

The Hospital Management System is a simple relational database project developed using MySQL.

The system is designed to store and manage information about patients, doctors, departments, appointments, treatments and bills.

This project demonstrates important Database Management System concepts using SQL.

## Technologies Used

- MySQL
- SQL
- Visual Studio Code

## Database Tables

The project contains the following tables:

1. Department
2. Doctor
3. Patient
4. Appointment
5. Treatment
6. Bill

## DBMS Concepts Used

- Database creation
- Table creation
- Primary Keys
- Foreign Keys
- Constraints
- INSERT
- UPDATE
- SELECT
- WHERE
- JOIN
- GROUP BY
- Aggregate Functions
- Subqueries
- Views
- Transactions
- COMMIT

## Main Features

- Store patient information
- Store doctor information
- Manage hospital departments
- Manage appointments
- Store treatment details
- Manage patient bills
- Generate reports using SQL queries
